# Contributing

Use this short path:

1. Read `README.md`.
2. Read `docs/project-standards.md`.
3. Follow `docs/agent-session-checklist.md`.

## Required for substantial changes

- Run relevant checks from `docs/project-standards.md`.
- Update `CHANGELOG.md` (`Unreleased`).
- Update `docs/decision-log.md` when durable decisions are made.
- Update `docs/limits-registry.md` for discovered/removed limits.
- Update `docs/agent-handoff.md` with validation + risks + next step.

## Commit style

- Keep commits small and scoped.
- Do not mix unrelated cleanup and behavior changes.
